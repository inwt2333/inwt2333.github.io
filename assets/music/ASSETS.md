# 留声室素材

`classical-room.webp`：用户于 2026-11-03 提供的古典听音室背景，由用户生成并提供用于本次网站制作；从提供的 PNG 压缩为 WebP，1672 × 941，无额外生成图片。

`classical-room-mobile.webp`：用户提供的古典手机端背景，941 × 1672。
`chinese-room.webp` 与 `chinese-room-mobile.webp`：用户提供的华语桌面端与手机端背景，分别为 1672 × 941、941 × 1672。三张新图均由原 PNG 转为 WebP。

western-room.webp 与 western-room-mobile.webp：用户于 2026-11-06 提供的欧美桌面端与手机端背景，分别为 1672 × 941、941 × 1672；由原 PNG 压缩为 WebP。

japanese-room.webp：用户于 2026-11-06 提供的日本桌面端背景，1672 × 941；由原 PNG 压缩为 WebP。手机端暂用这张图的响应式裁切，等待专用竖图。

漫游馆当前使用 CSS 光影背景。后续可替换对应背景规则，不影响收藏数据与编辑器。

唱片、封套与标签由 CSS 绘制。专辑封面来自用户添加歌曲时网易云音乐返回的原始图片地址，按需加载，失败时显示素色封套。
