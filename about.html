关于这趟列车

这里是 Inwt 的站台。我喜欢铁路图那种感觉——每条线路都有自己的颜色和终点， 又总能在某座车站交汇。所以干脆把小站画成了一张铁路图：你刚才在门厅看到的一切，就是这里的一切。

列车长

我是 Inwt，东北人，如今在上海读 AI。专业上关心 LLM 推理与 Agent 系统，好奇心大多花在「如何让一群智能体好好合作」这类问题上，偶尔得逞，经常碰壁。

课余是学校交响乐团的一名小提琴手，古典乐听得多，顺手把全国的演出信息整理成了门厅里的「乐律线」。喜欢在城市里走路，参加过城市定向，也和同学一起写了「魔都·Explore」这个小应用，专门收藏想去的地方。摄影是手机随手拍的档次，胜在真诚。

这站怎么修的

小站是纯静态页面：没有框架、没有后端、没有访问统计，你的足迹不出站。 照片由手机直传到电脑，本地脚本读取拍摄坐标后生成 WebP 与缩略图，随 git 一起发布。

门厅的轨道有日间与夜间两套配色，默认跟随系统，也可以用门厅右上角的按钮手动换乘。 字体和地图脚本也都收进仓库里，尽量不依赖外部服务——毕竟一趟能准点的车，靠的是自己的轨道。
